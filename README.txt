旧版と同じ場所に index.html / app.js / style.css を上書きしてください。同一オリジンの既存 localStorage キーを維持しています。
バクグラ回数反映設定を廃止。イベント手打ちではフルコンしない前提。
通常手打ち：フルコン930個、非フルコン836個。通常バクグラ774個。イベント曲875個消費。
pt差が手打ち・バクグラの既存pt単価に一致する組合せを検索し、クリア回数とFC回数で絞ります。
pt・クリア回数ともに増加なしの場合は通常曲バクグラと仮定し、曲時間と待機15秒から推定します。未プレイとの区別はできません。混合区間も既知のプレイ時間を差し引き、通常曲バクグラを0回～推定上限で表示します。手打ち待機は通常26秒・イベント27秒と仮定。イベントバクグラのptがまとめて反映される場合は時間推定に誤差が出ます。
