乃木フェス ライバル分析ツール 初版

ZIPを解凍し index.html をブラウザで開くか、3つのWebファイルをGitHub Pagesに公開してください。
初期設定 → スクショ → 分析・履歴 の順に使用します。
OCRと日時のメタデータ解析にはインターネット接続が必要です。画像はブラウザ内で処理する設計ですが、外部CDNからライブラリ・学習データを読み込みます。
OCRは実際のランキング画面で未検証です。誤認識・空欄の場合は手入力してください。撮影日時がない場合は更新日時を参考にします。
記録はブラウザのlocalStorageに保存します。画像自体は保存しません。ブラウザのデータ削除で消えます。
推定は簡易モデルです。ランキングptの反映時刻とアイテム消費時刻は異なるため、正確な残数を特定できません。手打ちや特攻変動は自動判定しません。実測ptを設定で上書きできます。
通常曲はLP81の曲774個、渋谷ブルースのみ既存ツールのLP75仕様714個として計算します。

Ver.1.2: スクショ間比較、手打ち・バクグラ混合逆算、累計追加。通常曲774個固定。手打ち自動ptはバクグラ+1656pt（実測上書き可能）。反映済みptに対応する消費数であり、実際の区間内消費は確定不可。
